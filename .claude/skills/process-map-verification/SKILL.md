# Проверка — Карта E2E-процессов In.Plan

Используй этот скилл в Claude Code для текущего запроса пользователя, в том числе при явном вызове `/process-map-verification`. Учитывай [CLAUDE.md](../../../CLAUDE.md); из правил с областью действия читай только относящиеся к изменяемым файлам. Ссылки на исходники ниже относятся к этому проекту; предметные правила и проверки применяй в пределах запрошенной задачи.

Все пути ниже относятся к корню проекта. Перед изменением читай действующие AGENTS.md в области правки; этот скилл дополняет их. Используй подтверждённые источники ниже, а не ограничения похожего соседнего проекта.

## Сценарии

Проверь обзор → детализацию → возврат, deep-link, подсветку входящих/исходящих связей и обе сборки SNP/MRP. В iframe проверь base path и открытие разрешённых ссылок. Успешный e2e с нулём тестов не считать подтверждением сценария.

## Доступные точки входа

- `package.json` (рабочая папка `.`): `npm run build`, `npm run check`, `npm run test`, `npm run e2e`.

Это обнаруженные точки входа, а не требование запускать всё при каждой правке. Перед выполнением перечитай script в текущем package.json: команды могли измениться или требовать локальную БД/браузер. Запускай релевантные проверки и обязательные ворота проекта. Не запускай seed, очистку БД, публикацию или развёртывание как проверку. Для изменения только скиллов проверяй формат, источники и смысл инструкций; сборка приложения этого не проверяет.

В результате назови проверенный сценарий, команду и наблюдаемый результат; отдели выполненное от проверки, недоступной из-за окружения.
