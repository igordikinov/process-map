# Карта E2E-процессов In.Plan

Используй этот скилл в Claude Code для текущего запроса пользователя, в том числе при явном вызове `/process-map-development`. Учитывай [CLAUDE.md](../../../CLAUDE.md); из правил с областью действия читай только относящиеся к изменяемым файлам. Ссылки на исходники ниже относятся к этому проекту; предметные правила и проверки применяй в пределах запрошенной задачи.

Все пути ниже относятся к корню проекта. Перед изменением читай действующие AGENTS.md в области правки; этот скилл дополняет их. Используй подтверждённые источники ниже, а не ограничения похожего соседнего проекта.

## Рабочий подход

Содержимое процесса меняется в src/data, геометрия — существующим layout, взаимодействие — React Flow/Zustand. SPEC имеет приоритет над PRD. Сохраняй ID шагов, ссылки между уровнями, входы/выходы и интеграции; перестановка узла не должна менять смысл ребра. SNP и MRP собираются разными режимами. Шрифты и иконки входят в статический бандл.
